# PowerGridAI – Smart Electricity Grid Management System

## Project Overview

PowerGridAI is a Smart Electricity Grid Management System developed using Data Structures and Algorithms (DSA). The project focuses on efficient management, monitoring, and optimization of electricity distribution networks through three case studies mapped to Course Outcomes (CO1, CO2, and CO3).

---

## Case Study 1 – Electricity Billing Management System

### Description

This module manages electricity customer records efficiently using AVL Tree. It stores customer details such as Customer ID, Customer Name, and Bill Amount while maintaining balanced data for faster searching operations.

### Data Structure Used

* AVL Tree

### Features

* Add customer records
* Search customer information
* Display sorted customer records
* AVL Tree balancing using rotations

### Time Complexity

* Insertion: O(log n)
* Search: O(log n)

---

## Case Study 2 – Smart Energy Monitoring System

### Description

This module monitors electricity consumption across different regions using Segment Tree. It performs efficient range queries to analyze energy usage and consumption statistics.

### Data Structure Used

* Segment Tree

### Features

* Store electricity consumption data
* Build Segment Tree
* Perform Range Sum Queries
* Analyze regional energy consumption

### Time Complexity

* Segment Tree Construction: O(n)
* Range Query: O(log n)

---

## Case Study 3 – Power Distribution Network Optimization System

### Description

This module represents power stations and transmission lines as a graph. Graph algorithms such as Breadth First Search (BFS) and Depth First Search (DFS) are used to analyze connectivity and optimize power distribution.

### Data Structure Used

* Graph (Adjacency Matrix)

### Features

* Power station connectivity analysis
* Breadth First Search (BFS)
* Depth First Search (DFS)
* Power network traversal

### Time Complexity

* BFS: O(V + E)
* DFS: O(V + E)
